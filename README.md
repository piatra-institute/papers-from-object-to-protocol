# From Object to Protocol

A Genealogy of the Artwork as Specification.

The identity of an artwork has shifted, in successive episodes, from the finished object toward the rule-bound specification. The view that an artwork is a singular artifact expressing an artist's interiority is a late and historically specific configuration. Earlier regimes treated images as ritual instruments, dynastic technologies, devotional interfaces, and workshop products whose identity was fixed by function and rule. Twentieth-century conceptual and score-based art relocated the work into the certificate, the score, and the instruction; generative code art added editioned variability through deterministic seeds. A third, emerging migration extends the same structure to model-mediated work, in which the artwork is an executable package of prompts, reference assets, model recommendations, seed ranges, and licenses, realized by a model. We call this form *latent score art* and treat it as a subcategory of AI art. The first two migrations rest on a large inventory of named, conserved works; the third rests on a few verifiable instances (the trained-model and protocol works of Holly Herndon and Mat Dryhurst, and the autonomous system Botto) and on hypothetical cases, and is presented as an emerging category. We define a *protocol* as a specification that is substrate-relative, bounded, transferable, editioned, and governed, and show how each migration adds properties to this inventory. On the legal side, authorship remains narrowly defined while the art-historical account of authorship widens, and the two should be kept distinct. Markets must handle model drift, changing governance terms, and uncertainty about what a buyer owns. Criticism must treat training corpora, model versions, and prompt grammar as properties of the medium.
